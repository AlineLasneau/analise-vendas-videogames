# Análise de vendas e avaliações de videogames

## Objetivo
Analisar dados de vendas e avaliações de videogames utilizando Python e Pandas.

## Análises realizadas
- Vendas por gênero e plataforma.
- Vendas por ano de lançamento.
- Vendas por editora.
- Comparação de vendas por região.
- Relação entre avaliações e vendas.
- Identificação dos jogos com maiores vendas globais.

## Tecnologias
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
